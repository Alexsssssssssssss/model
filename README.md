## 用户网站

安装64位Python3.12，解压后双击 **start-dispatch-site.cmd**。首次设置管理员口令与邀请口令。

- 管理员入口：`http://127.0.0.1:8780/admin`，管理员选择平台后保存完整天凤账号ID，或雀魂账号、密码及登录方式。
- 用户入口：`http://127.0.0.1:8780/`，凭邀请口令登录，选择天凤或雀魂，输入个室/友人房号、选择1–3个AI模型后派遣。
- 账号由后台自动分配；用户不需要填写或获知账号ID。
- 用户页仅提供「与我对战」和自己的任务进度；无训练、段位战、账号管理、统计或模型对照入口。
- 支持天凤个室或雀魂国服标准四人三赤半庄友人房，每次一把。雀魂仍为实验接入，真实账号完整对战未验证。

管理员口令不要给用户。账号与口令哈希仅存本机，包内不包含任何账号、口令配置或原始训练牌谱。网站运行在哪台机器，AI使用哪台机器的网络。目前未上线公网；有云服务器后通过HTTPS反向代理部署，见说明。

## 本机管理控制台

`start-ai-console.cmd`保留为本机管理工具；不要将这个旧管理接口直接公开。不要在网站与旧控制台中同时运行同一账号。个室号可自行输入1000–9999，不再固定2456。更新前关闭旧窗口，保留`.venv`、`dispatch-accounts.local.json`、`dispatch-site.local.json`和历史`runs/dispatch`。

## 模型与验证限制

v5是基于监督基准的真人牌谱微调，个人有效损失10%、高手90%，排除混沌恶；不是争一/平衡/避四顺位奖励强化学习版。原基准仍为默认。

固定2000半庄评估新模型平均顺位2.463、旧2.537，改善95%区间[-0.010,+0.158]，未达到显著标准。不同风格对手1800半庄亦未证明显著提升。不要据此宣称天凤段位或所有恶手已修复。

最近发现回放提取提前带入后续杠宝，提取器时序修复已验证，新特征重建已完成，v6三种风格训练另行进行。当前下载模型仍保留原基准与v5冻结权重。在线对战和冻结模拟评估按实际公开事件运行，不能将提取问题等同于在线偷看。
