## 启动与账号

安装64位Python3.12，解压后双击start-ai-console.cmd；保留启动窗口。网页顶部「本机账号」添加独立AI账号，天凤需完整登录ID而非昵称。账号保存在本机dispatch-accounts.local.json，不要上传或分享。更新前关闭旧窗口，覆盖程序文件，保留.venv、账号配置、runs/dispatch历史。

## 派遣

「派遣对战」选择个室号1000–9999、模型和账号，1–3个AI与真人对战；四AI内战需要4个独立账号。可选择四AI强化学习，但两个现有模型本身属于监督学习，界面的争一/平衡/避四目标仅在你主动开启新个室强化学习任务时使用，不代表旧模型仍可选。

段位战模式选择一个账号与模型，一般/上级/特上/凤凰，四麻赤牌东风/半庄，设置目标完整对局数。资格由天凤判定，到达局数停止，异常时停止，不自动换场。真实长时间连接稳定性尚未保证；东风策略尚未单独评估。按天凤对AI参战的规定使用。雀魂恢复为实验友人房派遣：仅国服账号/邮箱密码或手机号密码登录，标准四人三赤半庄。房主创建房间后填入房间号，AI准备后由房主开始，等待上限5分钟；不支持雀魂段位战或强化学习。真实账号登录和完整对局尚未验证，151的旧协议问题已修复，仍需真实账号验证。

## v5是什么

v5从监督基准继续学习真人原始牌谱，个人有效损失10%、高手90%，混沌恶排除。不是争一、平衡、避四顺位奖励强化学习模型。固定2000半庄评估新平顺2.463、旧2.537；改善95%区间[-0.010,+0.158]，未达到显著标准。不同风格对手1800半庄也未证明显著提升。两把真人实战观察不能证明天凤段位。测试版提供实验使用，不保证所有恶手已解决。

赤五/普通五合法动作的解析已修复，不能在普通五同样可合法打出时无意义丢赤。拆搭子和面对立直进攻需结合进张、改良、役、打点、牌风险、巡目和点差判断，不能单凭向听或是否有现物判错。

「任务与统计」保存牌谱链接、对局事件与统计，下载CSV及诊断。数据位于runs/dispatch；对局中断不计为完整对局，不用于更新模型。包内含TEST-MODEL-EVALUATION.json冻结评估摘要，不包含账号或原始训练谱。

天凤网关来自tomohxx/mjai-gateway，MIT许可证随包，未使用其训练牌谱或策略权重。

## 20261014.5：雀魂151修复

当前官方客户端为Unity/WebGL，旧`game.ResourceVersion`和`GameMgr`控制台命令不适用。旧`version.json`的0.11.252.w不能用于Unity登录。工具现从官方Unity资源索引解析资源版本（验证时0.16.283）和首页包版本（4.0.47），使用`WebGL_2022-资源版本`；正确解压资源索引后取文件名，不从压缩字节中猜哈希。线路握手在登录和游戏鉴权之前发送平台字段（protobuf第6字段）Web。

服务器已实测：不存在的合成账号由151变为1002（账号不存在）。这验证握手修复，不等于真实账号登录或完整对战已通过。更新后仍需在本机验证。关闭旧进程，覆盖后运行启动脚本，脚本会安装新增的UnityPy依赖；仅刷新网页不会更新后端。手机号密码登录时需在账号配置选择对应登录方式。

解析Unity资源使用[UnityPy](https://github.com/K0lb3/UnityPy)（MIT）；协议核对参考[majsoul-autopilot登录实现](https://github.com/happy-shine/majsoul-autopilot/blob/81365068a4560383329d6b869f19060706fbb1b5/crates/protocol/src/login.rs)和[MajsoulPaipuConvert握手说明](https://github.com/jeff39389327/MajsoulPaipuConvert/blob/4387a3e66cc4e5792cb1df8244d6bf11b95ce718/ms_patch.py)。包内不含官方游戏资源、账号或密码。

20261014.5修正两个Windows启动脚本漏装UnityPy的问题。已有虚拟环境也会检查并补装UnityPy==1.25.4，无需重新安装模型或Torch。若已下载上一包，可在程序目录执行 `.\.venv\Scripts\python.exe -m pip install UnityPy==1.25.4` 后重启。

20261014.5修正开局ActionMJStart被当作未知事件的问题。它是无字段的开场动画标记，不调用模型或重复初始化对局；随后ActionNewRound才提供起手牌。模拟完整事件流已加入这一真实开局顺序，验证进入首局后v5正常作出合法决策。真实完整半庄仍待验证；当前不支持断线后中途恢复，已有未结束对局需先在官方客户端处理，再开始新半庄。

同版还统一雀魂日志使用UTF-8写入；诊断读取兼容旧Windows GBK文件，跳过损坏诊断并保留最初异常，显示正确阶段与已停止状态。已用实际任务工作线程模拟GBK诊断和损坏文件，确认异常处理不会再次崩溃。
